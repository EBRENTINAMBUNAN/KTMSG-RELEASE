# KTMSG - Android Application Release

Repositori ini dikhususkan untuk mendistribusikan file instalasi (APK) dari aplikasi Android **KTMSG**. 

## 📥 Cara Unduh & Instalasi

Untuk menginstal aplikasi ini ke perangkat Android Anda, ikuti langkah-langkah berikut:

1. Buka halaman [Releases](https://github.com/EBRENTINAMBUNAN/KTMSG-RELEASE/releases) di repositori ini.
2. Di bawah rilis **KTMSG Versi (Latest)**, cari bagian **Assets**.
3. Klik dan unduh file bernama **`KTMSG-1.0.apk`** (pilih versi terbaru atau latest)
4. Pindahkan file APK ke perangkat Android Anda (jika mengunduh dari komputer), atau buka langsung dari folder *Downloads* jika mengunduh melalui peramban HP.
5. Klik file APK tersebut untuk memulai instalasi. 
   *(Catatan: Jika muncul peringatan keamanan, pastikan Anda telah mengaktifkan izin "Install from Unknown Sources" atau "Instal dari sumber tidak dikenal" pada pengaturan keamanan Android Anda).*
6. Selesaikan instalasi dan buka aplikasi.
